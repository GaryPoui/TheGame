# Dirección visual y sonora actual

La instrucción del 2026-10-23 reemplaza la revisión realista: animación de los años treinta,
con referencia visual Cuphead, ambiente tranquilo y apertura tétrica. Dirección, encuadres,
paleta, tiempos, accesibilidad, fuentes y limitaciones en [Teatro de tinta](ink-theatre.md).

Prioridad: símbolos y decisiones de mesa, personaje expresivo, entorno como marco. Trazos
de tinta, colores mates, acuarela y formas curvas; carta violeta como foco del captor.
Fondos y personajes ilustrados sobre props interactivos Babylon.js. No usar piel fotográfica
ni texturas escaneadas para nuevos personajes. Mantener continuidad con los tres assets v3.

La presentación realista anterior se conserva como [registro histórico](visual-upgrade.md),
con sus licencias y recursos; ya no define la dirección visual vigente. El prompt original
permanece intacto para trazabilidad, sujeto a las instrucciones posteriores del usuario.

Audio: tono discreto en aparición, efectos de resultado existentes, volumen y mute. El texto
contiene toda la información relevante. La reducción de movimiento elimina balanceo/fundido
y abrevia la oscuridad. La partida no tiene decisiones con tiempo obligatorio.
