# Riesgos, supuestos y decisiones pendientes

| Riesgo | Impacto | Mitigación / señal para actuar |
| --- | --- | --- |
| Tableros se sienten cuestionario | Alto | Decisiones modifican riesgo y recursos; probar mesa 005 antes de campaña |
| Azar interpretado como castigo | Alto | Tres registros separados, reconocer decisión correcta con mala tirada |
| Campaña se alarga | Medio | Probar duración; reducir diálogo/variantes antes de quitar conceptos |
| Personajes caros de producir | Alto | Un asistente representativo, reutilizar rig y poses; recursos licenciados |
| Skills engine-specific | Alto | APIs oficiales Babylon, router descartado; no ejecutar scripts por instalación |
| Assets sin licencia | Alto | Registro por archivo y bloqueo de importación; enlaces no equivalen a permiso |
| GPU integrada insuficiente | Alto | Presupuestos, presets y escena representativa; medir antes de detalle |
| Datos guardados inválidos | Medio | Validación estricta, backup, aviso y reinicio explícito |
| Ayuda parece certificar dominio | Medio | Insignia aprobado con ayuda y transferencia separada |
| Versión npm incompatible | Medio | Pins y lock, verificar tipos/build en 001 antes de UI |
| Escena de cautiverio incómoda | Medio | Aviso breve de tono, intro omitible, sin violencia gráfica ni movimiento forzado |

Supuestos de diseño: español rioplatense inicial, lectura de fracciones básicas, público inicial
adulto/general con baja experiencia estadística; no afirmar clasificación por edad oficial.
Navegador escritorio moderno con WebGL; móviles y lectores de pantalla para navegación 3D completa
necesitan investigación adicional, sin quitar la semántica HTML mínima.

Preguntas no bloqueantes para prototipo: público educativo específico, hardware de referencia,
presupuesto de arte/doblaje, proveedor final hosting y licencia del código propio. Hasta decidir,
no se concede licencia general del proyecto; sólo se conservan licencias de terceros. No adoptar
MIT para trabajo del usuario sin decisión explícita. Tipografías y assets aún no descargados
son candidatos, no recursos integrados.

Siguiente decisión de producción: validar mesa 005 en sala simple con un asistente y luego elegir
si adaptar recursos o modelar propios. No se debe producir toda la campaña antes de esa revisión.
